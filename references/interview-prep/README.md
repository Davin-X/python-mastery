# Interview Prep

Focused, categorized interview material that maps to the `python-mastery`
curriculum. Start with the fundamentals, then move outward to the areas where
you are weakest.

## Content

**`interview_questions_mastery.ipynb`** — a structured overview notebook with
representative questions across five areas:

1. **Python fundamentals** — types, data structures, comprehensions, generators
2. **Data structures & algorithms** — complexity, hashing, search/sort, DP basics
3. **Statistics & probability** — distributions, sampling, hypothesis testing
4. **Machine learning** — bias/variance, regularization, evaluation, feature engineering
5. **System design & behavioral** — architecture basics, process questions

> Honest note: this is a **curated primer** with representative questions, not a
> 2,000-question bank. Use it to check breadth, then drill depth with books like
> *Cracking the Coding Interview* and LeetCode-style platforms.

## Suggested flow

1. Complete the 14-week curriculum in `../../LEARNING_PATH.md`.
2. Work through `interview_questions_mastery.ipynb` once at the end.
3. Revisit any area where a question feels unfamiliar; the notebook links back
   to the relevant source notebooks.
4. Practice the standalone problems in `../../practice/problems/` and the file
   organizer in `../guides/automation_and_devops.md` for hands-on coding.
