# Security Policy

## Supported Versions

This is a learning repository. Content and code are maintained on an
as-time-permits basis on the `main` branch.

| Source | Supported |
| ------ | --------- |
| `main` | :white_check_mark: |

## Reporting a Vulnerability

This repository contains teaching materials, not a production service, but we
still take reports seriously.

- **Preferred:** Open a private vulnerability report via
  **GitHub → Security → Report a vulnerability** (recommended over email).
- **Alternative:** Contact the maintainer directly.

Please include:
- The affected file(s) and line(s)
- A minimal description of the issue
- Suggested fix (if known)

You should receive a response within a reasonable time. Please do not open a
public issue for a security-related problem.
