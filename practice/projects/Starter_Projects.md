# Quick Start Projects

Do 1-3 projects from each category. Focus on learning, not complexity.

## Beginner Projects (1-2 weeks)

### 1. Calculator App
- `+ - * /` operations
- Error handling for division by zero
- Clean input/output

### 2. Todo List Manager
- Add/view/delete tasks
- Save to file
- Mark tasks complete

### 3. Simple Game (Rock Paper Scissors)
- Player vs computer
- Score tracking
- Input validation

## Intermediate Projects (2-4 weeks)

### 4. File Organizer
- Sort files by type/extension
- Create directories
- Handle duplicates

### 5. Basic Contact Book
- Add/search/update contacts
- Save to file/database
- Search functionality

### 6. Weather App Script
- API integration
- Display formatted data
- Error handling

## Concepts to Practice

**All Projects Focus Here:**
- ✅ Functions & modular code
- ✅ Error handling (try/catch)
- ✅ File I/O operations
- ✅ Data validation
- ✅ Clean code structure
- ✅ Documentation

## Project Workflow

1. Plan: Write pseudocode first
2. Build: Implement core features
3. Test: Run with edge cases
4. Refine: Add error handling
5. Document: README + comments

## Success Metrics

- ✅ Code runs without crashes
- ✅ Handles invalid inputs gracefully
- ✅ README explains usage
- ✅ Code is understandable
- ✅ Completed within deadline
