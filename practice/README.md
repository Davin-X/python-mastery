# Practice

Choose a practice route based on the time you have:

| Route | Best for | Start here |
|-------|----------|------------|
| Short problems | Focused function-writing and interview patterns | [`problems/README.md`](problems/README.md) |
| Weekly projects | Combining skills into a small application | [`projects/README.md`](projects/README.md) |

## Short problems

Problems are ordered from fundamentals toward common interview patterns. Each
folder has a prompt, an unfinished `starter.py`, and a reference `solution.py`.
The curriculum notebooks add 41 topic-matched function-writing prompts; the
interview-prep notebook adds 10 more. Their answer keys live separately under
[`solutions/`](solutions/), grouped into five files rather than one per notebook.

1. Read `problem.md` and clarify the expected behavior.
2. Implement the function in `starter.py` without opening the solution.
3. Run it with `python starter.py`; the included checks should print `OK`.
4. Review the reference solution and compare correctness, complexity, and edge cases.
5. Mark progress in the table in `problems/README.md`.

The problems use only the Python standard library. Their inline checks run with
Python and do not require pytest.

## Weekly projects

The projects are assignment specifications, not finished applications. Build
them after the matching notebook week, then use each acceptance bar in
[`projects/README.md`](projects/README.md) to review your work.

## Sample data

[`data/`](data/) contains small datasets for project work. Read its README for
the schema and intended exercises before using a file.
