## 🚀 Quick Start Guide

### Prerequisites
- Python 3.8 or higher
- Jupyter Notebook/JupyterLab
- Basic computer literacy

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/python-mastery-platform.git
   cd python-mastery-platform
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Launch Jupyter:**
   ```bash
   jupyter notebook
   # or
   jupyter lab
   ```

4. **Start learning:**
   - Open `01_python_basics.ipynb`
   - Follow the curriculum week by week
   - Execute code cells and experiment!

### Environment Setup (Recommended)

```bash
# Create virtual environment
python -m venv python_mastery_env
source python_mastery_env/bin/activate  # On Windows: python_mastery_env\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Launch Jupyter
jupyter lab
```
